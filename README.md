# classroom-games

課堂音樂遊戲（iPad 適用）。

- `sound-drop/`：Sound Drop 排位賽。錄音來自 VSCO-2 Community Edition（Versilian Studios，CC0）。
- `backend/Code.gs`：Google Apps Script 一次性房間排行榜（部署為網頁應用程式，存取權：所有人）。
- `chord-hunter/`：和弦獵人。兩關：第 1 關「砌和弦」（6 題疊三度＋6 題速認）；挑戰關「聽和弦」（C I・F IV・G V・Am vi）。挑戰關開房時由老師機播聲，學生機只作答：① 試聽 → ② 試玩 6 題（唔計分）→ ③ 正式 12 題。老師狀態寫喺排行榜一行特別記錄（pid 以 h0st 開頭），學生機每 2 秒左右讀取。後台 stage：terms／fam＝第 1 關、mix＝挑戰關。鋼琴採樣：tonejs-instruments（CC BY 3.0）。
- `sing-race/`：合唱過關（空中游水）。老師電腦開，用咪聽全班。一關到尾，主要睇音準；聲量只要保持喺一個範圍（夠大聲畀咪聽到、唔好嗌）。人嘅高低＝音高（跟導唱紫色線，或者睇係咪喺個調入面），左邊 bar＝聲量（綠色範圍）。人頭頂吊住一排刺：越大聲刺越低，太大聲就撞到，即扣一粒心；太細聲、走音、亂嗌連續幾秒都扣一粒。易 5 粒心、中 4 粒、難 3 粒（難度越高，音準要求越嚴、扣心心越快）。開始時有 5 粒點倒數，同時出第一句歌詞。老師設定：載入伴奏、貼歌詞＋撳空白鍵定時間（定埋結束位置）、喺遊戲錄導唱或載入導唱檔、調（自動偵測）、聲量範圍、唱歌偵測。咪固定用 MacBook 本身個咪（唔會跟 macOS 轉去附近 iPhone），可以喺設定揀。伴奏、歌詞、導唱只存喺該部電腦嘅瀏覽器，唔會上載。
